# ResumeBuilder — Веб-приложение для создания резюме

## О проекте

**ResumeBuilder** — это веб-приложение, позволяющее пользователям быстро и удобно создать резюме с нуля, выбрать шаблон и экспортировать результат в PDF.

## Установка библиотек и запуск проекта

1. Клонируйте репозиторий:
```bash
git clone https://github.com/yourusername/resume-builder.git
cd resume-builder
```

2. Установите зависимости:
```bash
npm install      # frontend (client/)
pip install -r requirements.txt  # backend (Flask)
```

3. Запустите frontend:
```bash
npm start
```

4. Запустите backend:
```bash
cd backend
python app.py
```

## Администрирование проекта

| Действия пользователя               | Действия администратора / системы         |
|---------------------------------------------|------------------------------------------------------|
| Заходит на сайт                          | Отвечает сервер, показывает главную страницу |

## Технологии
- **Frontend:** React, TailwindCSS, Redux
- **Backend:** Flask / Express
- **База данных:** Firebase / localStorage
- **Генерация PDF:** jsPDF, html2canvas
- **Дизайн:** минимализм, адаптивность

## Дополнительная информация о проекте
### Архитектура приложения
ResumeBuilder использует **клиент-серверную архитектуру** 
с четким разделением ответственности:
- **Frontend** (React) отвечает за интерактивность, рендеринг шаблонов и работу с UI.
- **Backend** (Flask) обрабатывает API-запросы, аутентификацию и взаимодействие с базой данных.
- **Хранение данных** реализовано гибко: для гостевых пользователей — localStorage,
- для зарегистрированных - БД

### Безопасность
- Реализована **валидация данных** на стороне клиента и сервера.
- Пароли хранятся в хешированном виде.

### Планы развития
1. Добавление **AI-ассистента** для автоматического наполнения резюме (например, на основе вакансии).
2. **Командные резюме** — возможность группировать несколько профилей для проектов.
3. **Расширенные шаблоны** с поддержкой портфолио (для дизайнеров, разработчиков).

### Возможность добавления уникальных фишек в будущем
- **Авто-предиктив** в полях ввода (например, подсказки навыков для IT-ролей).  
- **Dark Mode** для работы в ночное время.  
- **Статистика** по востребованности разделов резюме (на основе A/B тестов).
- **Monetization**: платные премиум-шаблоны или подписка на расширенные функции.

### Возможность интерграций и API
- Поддержка **Google Fonts API** для кастомизации шрифтов в резюме.  
- Использование **Cloudinary** для оптимизации загружаемых пользователем изображений.  
- Интеграция с **Telegram Bot API** для отправки готовых резюме прямо в чат.
