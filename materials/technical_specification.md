## 1. Описание проекта
Веб-приложение предназначено для создания резюме с возможностью выбора шаблонов и заполнения данных пользователем. Готовое резюме можно экспортировать в PDF или TXT.

## 2. Функциональные требования

### 2.1. WEB-сайт

#### Основные страницы:
- **Главная страница** (приветствие, краткое описание функционала).
- **Страница выбора шаблона резюме**.
- **Страница редактирования резюме** (ввод данных, настройка стилей).
- **Страница просмотра и экспорта в PDF или TXT**.

#### Элементы страниц (UI/UX):
- Поля ввода текста (ФИО, общая информация, стаж работы, наличие образования и т.д.).
- Загрузка фото пользователя.
- Кнопки сохранения, экспорта и скачивания резюме.
- Превью резюме перед экспортом.

#### Шаблоны резюме:
- Минимум 3 варианта дизайна (**классический, креативный, строгий**).
- Поддержка CSS-стилей для настройки внешнего вида.
- Шаблонные заготовки с вопросами о личных данных пользователя

#### Регистрация и авторизация:
- Через **e-mail и пароль**.
- **OAuth** (Google, GitHub).

#### Работа с файлами:
- Загрузка изображений (аватарки).
- Сохранение данных пользователя.
- Генерация или перевод PDF и TXT файлов

#### API и интеграции:
- Генерация PDF (например, библиотека **jsPDF**).
- Поддержка **локального хранения или базы данных**.

#### Хранение информации:
- Данные пользователя (резюме) сохраняются в **локальном хранилище** или **базе данных**.
- Возможность **редактирования ранее созданного резюме**.
- Хранение базовых шаблонов и основных фраз при работе с пользователем

### 2.2. WEB-навыки и боты (при расширении проекта)
- Возможность взаимодействия с **ботом** (например, Telegram-бот для генерации резюме).
- **Команды** для создания резюме через текстовые команды.
- **Автоматические подсказки** по улучшению резюме.

## 3. Технологический стек
- **Frontend:** HTML, CSS, JavaScript (**React/Vue при необходимости**).
- **Backend** (если требуется база данных): Node.js + Express / Firebase.
- **База данных:** Firebase / PostgreSQL / локальное хранилище.
- **PDF-генерация:** jsPDF, html2canvas.

## 4. Требования к дизайну
- **Современный адаптивный UI**.
- **Поддержка мобильных устройств**.
- **Минималистичный дизайн** без лишних элементов.

## 5. Экспорт и сохранение
- **Резюме можно скачать в формате PDF или TXT**.
- **Доступна функция автосохранения**.

## 6. Дополнительно
- Возможность **добавления дополнительных разделов** в резюме.
- **Интерактивный превью-редактор**.
- **Поддержка нескольких языков**.
- **Внедрение ИИ-помощника**.
